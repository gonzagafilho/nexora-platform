# NEXORA Platform

Version: v0.1.0

Bootstrap inicial do monorepo NEXORA Platform.

## Estrutura

- apps/
- packages/
- control-center/
- gateway/
- sdk/
- docs/
- scripts/
- docker/
- .github/workflows/

## Stack do monorepo

- Node LTS
- pnpm workspaces
- TurboRepo

## Comandos

```bash
pnpm install
pnpm build
pnpm lint
pnpm test
```

## Política desta etapa

Nenhum código de produção foi migrado nesta fase. Este repositório contém apenas o bootstrap estrutural da plataforma.
